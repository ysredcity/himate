# 当前设计与交互契约

本文件记录用户已认可并落实到当前工程的 UI 规则。针对新对话页的后续要求以本文件和实际实现为检查依据；历史截图仅作为当时状态的证据。

## 设计来源

- 基础：Pangea 沉浸式 Agent 模板及其交互约束。
- 新对话页：[Figma 节点 1971:42117](https://www.figma.com/design/2oejVUpaCbsVHfu1wYafYO/?node-id=1971-42117)。
- 已下载的 44 个素材：`apps/desktop-web/public/figma-home/`；对应 [清单](figma/asset-manifest.json)。保留图像比例及原位置，SVG 使用固有尺寸，不使用临时下载 URL。
- [原始 UED 文档](reference/UED-员工智能工作台V1.0.md)为上游参考，部分旧行为与当前用户修订不同。发现冲突需核实，不能直接回退用户已确认的交互。

## 首页

- 欢迎语为“Hey [虚拟头像] 有什么需要我搞定的？”，桌面标题区高 80px、顶部留白 112px；内容最大宽度 768px。
- 输入区桌面空态高 104px，Placeholder 为“发送消息给我”。图片样式入口 Tooltip 与可访问名均为“上传图片”；保留已有附件上下文菜单行为。
- 推荐区距输入区 24px，每组 3 项；桌面三列、移动端纵向排列。点击推荐填入输入框，用户发送后发起任务。
- 推荐区域悬停或键盘聚焦时才显示可用方向按钮；触屏上直接提供可用入口。第一页没有“上一组”，最后一页没有“下一组”。
- 翻页按钮背景使用不透明 `card` Token，悬停状态保持不透明，不使用半透明 muted 底色。
- 鼠标翻页使用 `transform` 横向移动，240ms、`ease-in-out`。键盘触发或 `prefers-reduced-motion: reduce` 时立即切换。非当前页必须 `aria-hidden` 且 `inert`，不能聚焦。
- 下方依次为：信数报表、我的应用、我的智能体、学习与成长、资讯。区块间距 40px，桌面内容最大宽度 1240px。
- “更多 / 全部 / 配置”及卡片入口使用可操作的本地演示；不暗示真实系统已接入。首页配置在当前新对话页组件生命周期内有效。

## 首页响应式

按 **新对话工作区容器宽度** 判定，使用命名容器 `home`，不以浏览器宽度替代；侧栏展开必须重新计算。

| 工作区宽度 | 报表 / 智能体 / 课程 / 资讯卡片 | 应用图标 |
| --- | --- | --- |
| <660px | 2 列 | 4 列 |
| 660–899px | 3 列 | 6 列 |
| 900–1099px | 4 列 | 8 列 |
| ≥1100px | 5 列 | 12 列 |

推荐卡片独立遵循每组 3 项的规则，不套用上述业务区块列数。

## 对话与产物

- 沉浸式形态：可收起左侧导航、中央对话流、按需打开右侧产物面板。默认新对话页导航收起。
- 导航宽度 240px，对话区下限 420px，右面板下限 320px。开启产物时低于 980px 先收导航，低于 740px 产物升级为全屏；移动端主要区域单独呈现。
- 保持“委托 → 执行 → 结论 → 可点击产物”闭环。执行过程反映真实演示复杂度，完成后默认收起；不强造规划层。
- 每轮智能体以虚拟头像和名称开场；结论与完整产物分开，产物用 Tab / 专注查看承载。
- 同一产物不重复建 Tab，切换会话即时清理面板。上传附件只提供元数据预览，不宣称解析正文。
- 高风险真实写操作若未来引入，必须有明确确认与结果回写；当前 Demo 不执行真实写操作。

## 视觉与无障碍

颜色使用语义 Token，主题色来源为物化 `theme.css`，不在业务组件写裸色值。正文以 15px / 1.6 为基准，辅助 14px / 20px，次要 12px。

纯图标按钮提供可访问名；键盘可完成核心任务，折叠 / 非当前页面不可聚焦；动效尊重减少动态偏好；移动端主要触控目标不小于 44px。修改时检查受影响组件，不把模板已有实现视为无障碍全面达标的证明。

## 验证宽度

触及响应式时至少覆盖工作区 390、659、660、899、900、1099、1100、1280px，及 1280px 浏览器展开侧栏后工作区约 1040px 的 4 列状态。仅涉及文案或非 UI 变更时无需重复全部宽度，但要说明实际验证范围。
