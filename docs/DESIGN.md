- 欢迎语为“Hey [虚拟头像] 有什么需要我搞定的？”，桌面标题区高 80px、顶部留白 112px；内容最大宽度 768px。

## 首页推荐指令

参考用户指定 AskHR 主应用首页，替代原每组三项的横向轮播。Composer 下方32px展示人事服务 / 差旅出行 / 日常办公 / 数据分析 / 知识学习五个圆角分类（每类5条，共25条），默认不选中、不展示指令。分类保持单行，桌面高36px、窄屏44px；按容器和实际按钮宽度测量，保留8px间隔并预留“更多”按钮，将右侧溢出分类收进Base UI下拉菜单。宽度恢复时自动移回；隐藏分类选中时“更多”显示与分类一致的深灰底 / 白色图文选中状态，菜单内标注已选。测量副本inert且aria-hidden，不进入键盘或辅助技术导航。

单击分类展开下方推荐列表；再次点击当前分类收起，切换分类仅显示新分类。选中分类使用foreground深灰填充与background白色图标 / 文字，悬停和展开时保持该配色，悬停或键盘聚焦时图标换为X。按钮提供aria-pressed、aria-expanded和aria-controls；收起列表从DOM移除，不能残留焦点。展开 / 切换分类时，列表整体从上方8px向下归位并淡入，200ms ease-out，仅transform与opacity；使用既有tw-animate-css，prefers-reduced-motion下禁用，收起保持即时卸载。

展开列表直接复用 Pangea 模板已有 `RecommendationList`，距分类20px、14px / 20px常规字重、水平内边距12px、垂直8px、圆角10px，右侧为左上箭头；悬停 / 聚焦用accent底色。桌面行高36px，窄屏至少44px且长文案换行。推荐项支持可选label：前置Medium标签、竖分隔线、muted描述，保留模板右侧左上箭头；未传label的对话后续推荐保持原样。

点击指令沿用prepareTask，只预填并聚焦Composer，不自动发送。通过focusRequest在草稿写入后将Selection折叠至编辑器末尾，重复选择同一条仍重新定位；手动输入不触发该定位。分类本身不选择专家；点击指令按条目的可选expert同时预填草稿与专家，没有expert的条目清空此前专家。首页推荐仍为人事服务5条带入人事专家、差旅出行5条带入差旅专家，其余15条不带专家；Composer专家菜单只列已安装专家（初始5位），不自动发送。已有六条指令内容与触发prompt保留，新增指令为草稿入口，不代表新增真实业务接入；数据与图标分别在home-data.ts、icon-registry.ts，交互在home-recommendations.tsx。

## 首页响应式

按 **新对话工作区容器宽度** 判定，使用命名容器 `home`，不以浏览器宽度替代；侧栏展开必须重新计算。

| 工作区宽度 | 报表 / 智能体 / 课程 / 资讯卡片 | 应用图标 |
| --- | --- | --- |
| <660px | 2 列 | 4 列 |
| 660–899px | 3 列 | 6 列 |
| 900–1099px | 4 列 | 8 列 |
| ≥1100px | 5 列 | 12 列 |

我的智能体在工作区 <480px 时改为1列，避免头像与描述挤压；平台横条使用上一节规则。

## Composer 复用

首页与对话页均使用 `composer.tsx` 的同一个 Composer，统一默认 welcome 外观、发送消息给我占位和添加上下文Plus / 语音 / 发送图标。空态高度104px；业务状态、附件和专家能力共用原实现。首页上下文菜单向下、对话页向上，适配各自位置；对话播放与审批待决期间保持禁用。

## 对话与产物

- 左侧置顶 / 普通对话菜单与对话顶部菜单均提供“重命名、置顶 / 取消置顶、删除对话”。删除项使用Trash2，文字 / 图标为destructive-foreground，悬停 / 聚焦背景为destructive-bg；确认按钮同样使用这两个语义Token，点击后共享确认弹窗，支持取消 / Esc。确认后从两类列表及已读集合移除；删除当前对话时回首页并立即清理产物Tab、图片查看器，删除非当前对话不打断当前工作。仅内存演示，刷新重置。

- 沉浸式形态：左侧导航（展开 / 图标栏）、中央对话流、按需打开右侧产物面板。默认为图标栏。
- 导航展开宽度 240px，收起为 52px 图标栏（不再完全隐藏），对话区下限 420px，右面板下限 320px。开启产物时低于 980px 导航退为抽屉，低于 740px 产物升级为全屏；<660px 只用抽屉，主要区域单独呈现。
- 图标栏自上而下：52px 高的顶部区（默认显示 28px 产品头像，悬停或键盘聚焦时在原位置淡入为 IndentIncrease「展开导航」按钮并显示 Tooltip，点击展开；减弱动效下无过渡）、主导航图标（首页 · 新对话、专家，激活态同展开侧栏）、24px 分隔线、「已置顶」（Pin）与「对话」（MessagesSquare）各一个图标、底部深浅色切换。按钮 36px、10px 圆角、16px 图标，主导航与切换按钮 Tooltip 在右侧显示名称；分组为空时隐藏该图标。
- 已置顶 / 对话图标悬停（100ms 打开、200ms 关闭）或点击 / 回车，在右侧 8px、顶部对齐处打开 280px 列表窗口：16px 圆角、8px 内边距，标题为分组名，最高 min(560px, 视口-24px) 可滚动。条目复用侧栏的对话行（状态 Badge、更多菜单）；「更多」菜单打开期间窗口不因指针移出关闭，菜单关闭或选中对话后窗口收起。当前对话所在分组图标为激活态；分组内有未读完成、等待回复或等待批准时图标右上显示 8px destructive 红点。
- 图标栏常驻时，对话页与专家页顶栏不再显示「展开导航」「新对话」按钮。
- 保持“委托 → 执行 → 结论 → 可点击产物”闭环。执行过程反映真实演示复杂度，完成后默认收起；不强造规划层。
- 产品身份头像为 primary 青绿圆底 + primary-foreground 的 HiMate 标识（对话气泡与提示符，源文件 `himate-graph.svg`，`resource-visuals.tsx` 的 HiMateMark），侧栏顶部与对话中未指定专家的轮次共用。尺寸：对话 24px 圆底 / 16px 标识，侧栏顶部 28px 圆底 / 20px 标识。
- 每轮智能体以虚拟头像和名称开场；结论与完整产物分开，产物用 Tab / 专注查看承载。
- 同一产物不重复建 Tab，切换会话即时清理面板。上传附件只提供元数据预览，不宣称解析正文。
- 高风险真实写操作若未来引入，必须有明确确认与结果回写；当前 Demo 不执行真实写操作。

## 视觉与无障碍

颜色使用语义 Token，主题色来源为物化 `theme.css`，不在业务组件写裸色值。正文以 15px / 1.6 为基准，辅助 14px / 20px，次要 12px。

纯图标按钮提供可访问名；键盘可完成核心任务，折叠 / 非当前页面不可聚焦；动效尊重减少动态偏好；移动端主要触控目标不小于 44px。修改时检查受影响组件，不把模板已有实现视为无障碍全面达标的证明。

## 验证宽度

触及响应式时至少覆盖工作区 390、659、660、899、900、1099、1100、1280px，及 1280px 浏览器展开侧栏后工作区约 1040px 的 4 列状态。仅涉及文案或非 UI 变更时无需重复全部宽度，但要说明实际验证范围。

## 独立移动端首页

首页主体最新设计来源为 [Figma 3264:36630](https://www.figma.com/design/2oejVUpaCbsVHfu1wYafYO/?node-id=3264-36630)，2026-10-23 用户要求以 402px 为设计基准；顶部与固定输入沿用此前确认的 1931:24400。实现位于 apps/mobile，不复用桌面响应式壳层。

- 基准宽 402px（验证默认以 402×874 宿主外壳为准，320 / 375px 只作窄屏补充，2026-11-11 用户提醒），应用/固定底部/抽屉最大宽 402px；窄于 402px 时宽度随视口收缩，宽屏居中展示，402px 时内容宽 370px；顶部状态栏与工作台标题各 44px，内容左右 16px，主体浅灰底和顶部蓝色光晕。
- 顺序：16:9 宣传轮播、信数报表、四列应用、智能体宣传头部与单列专家列表、海信生活、双列课程、双列资讯。标题 18/28px，正文 16/24px，描述 14/20px，元信息 12/16px；卡片圆角依原稿为 8/12/16px。
- 底部固定历史入口、48px 消息输入和飞书导航示意；内容底部预留 180px 加安全区。宿主栏只展示设计稿，不代表已接入；其点击显示说明。
- 全部与详情用底部 Base UI Dialog 抽屉，最高 88dvh；支持 Esc、焦点约束与回归。配置使用 Base UI Checkbox，保存后在内存中生效，关闭不保存。
- 轮播支持横滑与分页，应用支持横滑与分页；生活服务支持分页。第一页保留原稿，后续页用明确的示例内容。
- 余额默认隐藏：隐藏态眼睛图标为划线样式、次要色，金额显示 4 个 36px 粗体星号（与数字同行高 40px、视觉居中），「元」底部对齐；点击后显示 120.54 与正文色眼睛（2026-11-08 用户截图）；充值、语音和宿主导航仅显示未接入说明，无支付、权限请求或平台调用。
- 首页不再承载对话：底部输入框只读，点击进入 Agent 模式新对话页；历史按钮打开与 Agent 模式共用的会话抽屉。详见下文「移动端 Agent 模式」。
- 常规交互命中区至少 44px。轮播指示点使用 44px 按钮，视觉仍为 6px / 16px 小圆点；减弱动效时禁用过渡。首页仅实现设计稿浅色主题，Agent 模式深色不影响首页。
