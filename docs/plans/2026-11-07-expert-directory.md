# 专家目录实施计划

**Goal:** 在桌面工作台新增专家市场、我的专家、可调度页面，支持详情、收藏、上限10、召唤和受控自动匹配。

**Architecture:** AgentShell拥有页面路由、收藏和可调度名单；专家数据与匹配规则独立。复用侧栏和富Composer，仅人事 / 差旅可直接召唤；其他条目演示进入入口。本地Mock，无接口和持久化。

**Tech Stack:** React 19 / TypeScript / Vite 8 / Tailwind v4 / Base UI。

## 步骤

1. 新增expert-data.ts：12条跨渠道示例，初始可调度人事 / 差旅；建立纯函数约束上限、去重和匹配规则。
2. 新增专家页面与卡片：Base UI Tabs / Dialog，场景筛选、收藏、详情、召唤 / 进入、添加 / 移除名单。真实hover设备按hover显示，键盘聚焦和触屏可见。
3. 接入导航与壳层状态：利用现有capability-hub导航类型；打开目录收起产物，召唤返回首页携带专家。手动指定优先，未指定仅匹配名单；无匹配使用通用助手。
4. 验证纯规则：10上限、重复添加、移除后不自动匹配、手动覆盖；运行根gate并尝试浏览器相关交互与390 / 755 / 1280宽度。
5. 更新设计、架构、ADR、CHANGELOG和当前上下文；保留预览，不提交或推送。

## 验收

三个Tab列表和空态正确；卡片操作不触发详情；详情可关闭；收藏和调度独立；添加重复不计数，10满后Toast；进入无跳转；两位直接专家返回首页已选且不发送；移除名单不影响手动指定与历史会话。

## 执行结果

1–3、5已实现；第4步规则测试、根gate与SSR首屏检查通过。浏览器连接超时，实际交互及多宽度检查待补；未提交或推送。当前可直接召唤两位，其余条目可通过名单内示例关键词参与模拟自动匹配。详见当前上下文和最近交接。
