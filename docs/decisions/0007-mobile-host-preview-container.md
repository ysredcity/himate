# ADR 0007：移动宿主预览容器与产品网页分离

- 日期：2026-11-07
- 状态：已接受并实施；返回按钮行为由 [ADR 0009](0009-host-back-navigation.md) 部分替代

## 背景

顶部系统状态栏、工作台导航和底部飞书Tab栏属于加载HiMate的宿主环境，不是产品网页。将它们写入App会耦合滚动、底部占位和返回行为，也不便单独预览网页。

## 决策

在apps/mobile/src/preview中提供HostPreviewLayout和独立样式。默认入口渲染宿主布局，通过同源iframe加载带preview=web参数的HiMate网页；该参数只由main.tsx入口解析，App.tsx不依赖宿主布局。preview=web直接渲染产品。

外层三行网格为88px顶部、剩余高度的WebView和按402:90比例显示的宿主Tab栏，容器高100dvh。产品内部拥有独立文档、滚动、固定输入和弹窗。宿主按钮只展示说明，不驱动产品状态、不模拟真实平台接入。产品对话内部提供返回首页入口。

## 取舍

相比简单React包裹布局，iframe真实隔离宿主与网页的视口、CSS、固定定位和弹窗，代价是预览多加载一个文档。无需跨文档通信；本轮不增加SDK、路由库、后端或持久化。未来真实宿主可直接加载preview=web的独立产品入口，默认宿主外壳只用于本地演示，不构成真实飞书接入。

## 验证

根gate通过；浏览器验证375/402/900px宿主栏保持位置、产品独立滚动、输入无遮挡、宿主和产品弹窗分别显示、纯网页不含宿主DOM，以及对话/产物/返回首页。真机验证未运行。
