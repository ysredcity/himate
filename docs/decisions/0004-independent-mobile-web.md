# ADR 0004：独立移动网页应用

- 日期：2026-10-23
- 状态：已接受并实施

## 背景

用户要求基于 Figma 1931:24400 创建独立移动首页，保留桌面应用；当前桌面窄屏布局无法代表独立移动产品。

## 决策

新增 apps/mobile（@himate/mobile），沿用 React 19、TypeScript、Vite 8、Tailwind v4、Base UI 与 lucide-react。两应用不互相导入源码；基础组件以本地副本复用，不为此创建共享包。根 apps/* workspace 与唯一 package-lock.json 维持不变。

根 dev、build、lint、preview 默认仍为桌面应用；新增 :mobile 命令。移动开发端口 5174、预览端口 4174，均 strictPort，避免自动换端口。根 gate 顺序验证治理、桌面、移动。

## 备选与代价

不采用桌面内响应式分支，因为用户需要独立应用目录与运行生命周期；不采用原生移动栈，以控制本轮首页 Demo 的范围。当前独立维护组件副本，未来共享须另行决策，避免移动应用耦合桌面业务。

## 边界

无后端、鉴权、业务持久化或平台接入。飞书状态栏和导航图像为宿主环境示意；所有业务数字、内容和过程均为前端 Mock。0002 的目录命名原则继续有效，其中“未来移动端”在此落实。
